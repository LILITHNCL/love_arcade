# Assets locales de marejigweb

La Fase 1 no requiere imágenes locales de nivel. Las imágenes de producción se entregarán desde Cloudinary en AVIF fuente y transformaciones runtime.

Esta carpeta queda reservada para assets livianos propios del juego, por ejemplo iconos, efectos o documentación de créditos. No guardar aquí secretos ni dumps de imágenes Cloudinary.
